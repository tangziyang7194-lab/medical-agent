AI 导诊系统使用说明

用户端 / 管理端 · DeepSeek V4 驱动 · 桌面完整版 / 云端精简版

👤 用户端功能

1. 注册 / 登录 / 找回密码

  • 注册：首页 → 用户端 → 注册，填写用户名 + 密码 + 确认密码
  • 登录：用户名 + 密码，登录状态 7 天内保持（关闭浏览器不丢失）
  • 忘记密码：登录页点「忘记密码？」→ 输入用户名 + 新密码即可重置（无需认证）

2. AI 对话问诊（核心）

  • 点击「💬 开始问诊」进入对话，描述您的不适（如：肚子痛、发烧）
  • AI 会像真实医生一样进行 4-5 轮完整问诊：症状与持续时间 → 严重程度与性质 → 伴随症状与诱因 → 既往病史/过敏史/用药 → 补充确认
  • 每轮只问 1-2 个问题；信息收集完整后自动生成诊断报告
  • 支持 🎤 语音输入（Chrome/Edge 浏览器）：点击输入框旁的麦克风直接说症状
  • 对话支持 🌓 深色/浅色主题切换（右上角按钮）

3. 查看诊断报告

  • 问诊完成 → 点「📋 查看诊断报告」→ 自动保存并跳转病历中心
  • 报告包含：建议科室、严重度、分诊等级、主诉、诊断结论、处理建议

4. 历史相似病例推荐

  • 生成报告后，对话区自动展示「📊 历史相似病例推荐」（基于向量相似度，3 条）

5. 病历记录（患者记录）

  • 与管理员端「咨询记录」同源（数据库存储），两端数据一致
  • 每条记录支持：📄 导出 Word / 📕 导出 PDF / 📧 发送到邮箱
  • 导出文件：Word（.docx）、PDF（.pdf），文件名含日期时间

6. 快捷问诊（选填）

  • 首页「⚡ 快捷问诊」：填写基本信息 + 症状 → 一键生成报告

🔐 管理端功能

1. 登录 / 注册 / 找回密码

  • 管理员注册：用户名 + 密码 + 确认密码（与用户端一致，无手机验证码）
  • 登录：用户名 + 密码；忘记密码 → 「忘记密码？」输入用户名 + 新密码重置

2. 仪表盘（数据概览 + 可视化）

  • 统计卡片：病例总数 / 咨询记录 / 患者数 / 向量数
  • 📈 可视化图表：科室分布 TOP10、严重度分布、近 30 天学习趋势（ECharts）

3. 病例管理

  • 搜索：支持症状、诊断、科室，也支持输入 ID 精确查询
  • 每条病例可「📄 详情」查看完整内容、「🗑 删除」
  • 表格含连续「序号」列（总数与序号对应）

4. 样例库

  • 只展示「典型病例」：关键词 ≥3 个且描述充分的案例（全库自动筛选）
  • 每页 100 条，最多 200 页；首页/上一页/下一页/末页翻页
  • 支持搜索与详情查看、删除

5. 📥 导出数据（合并菜单）

  • 点「📥 导出数据 ▾」展开菜单：📊 Excel / 📄 CSV / 📽 样例总结 PPT
  • 样例总结 PPT：9 页——总览 / 科室 TOP10 / 典型案例与 AI 分析（全库 20 条，每条含 AI 分析）/ 关键结论（≥500 字 AI 学习成果）

6. 🧠 向量数据库

  • 统计：当前向量条数；同步：一键将全部病例同步到向量库（有进度与完成提示）
  • 清空：清除向量数据（不影响 MySQL）；语义搜索：输入症状找最相似病例

7. 🩺 系统健康检查

  • 查看 MySQL / ChromaDB / DeepSeek AI / 管理员 状态与数据量

8. 🌿 健康养生建议

  • 每天 18:00 自动采集；可手动「🚀 立即生成」「🤖 AI总结」「🔄 实时去重」
  • 「🔗 公开页」查看用户端展示效果

❓ 常见问题

1. 修改代码 / 配置后不生效？

  • 修改 app.py、.env 等文件后，必须重启服务才生效（改 .py/.env 都要重启）。

2. 页面显示旧内容？

  • 浏览器缓存导致，请强刷：Ctrl + Shift + R（管理端页面同理）。

3. 服务启动报端口占用 / 功能时好时坏？

  • 可能启动了多个服务进程（同时监听 5000）。只保留一个：关掉多余的，或命令行执行 netstat -ano | findstr :5000 查看后结束多余进程。

4. 云端（PythonAnywhere）与本地（桌面版）区别？

  • 桌面完整版：全部功能（数据库、向量库、图表、PPT 导出、健康建议等）
  • 云端精简版：用户端只保留注册 + 问诊；管理端只保留非数据库功能（健康检查、添加管理员、用户咨询记录文件存储）；无 MySQL/向量库
  • 云端同步：Consoles → Bash → cd ~/medical-agent && git pull → Web → Reload

5. 📱 安卓 App？

  • 两个 APK：AI医疗问诊_安卓版.apk（用户端）、医疗管理端_安卓版.apk（管理端）
  • 默认连云端；⚙ 设置里可切换「桌面完整版」：填 http://电脑IP:5000（手机与电脑同一 Wi-Fi，电脑防火墙放行 5000 端口）

6. AI 提示无法回复？

  • 检查 .env 中 DEEPSEEK_API_KEY 是否有效（欠费/失效会返回错误）；修改后重启服务。

7. 数据在哪？

  • 病例/咨询存本地 MySQL；向量存本地 ChromaDB；管理员账号在 admin_users.json（用户端 users.json）。
